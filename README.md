# iris-eda
# Iris Dataset - Exploratory Data Analysis (EDA)

Welcome to my first data science project!  
This notebook contains a complete exploratory analysis of the famous **Iris Dataset**, using **Pandas**, **Matplotlib**, and **Seaborn**.

## Overview
The Iris dataset includes 150 samples of three species of iris flowers: *setosa*, *versicolor*, and *virginica*.  
Each sample includes 4 features:  
- Sepal Length  
- Sepal Width  
- Petal Length  
- Petal Width  

## Objectives
- Understand the structure of the dataset
- Perform statistical analysis
- Visualize relationships between features
- Extract key insights about the flower species

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Visuals Included
- Histograms
- Countplots
- Scatter Plots
- Boxplots
- Pairplots

## Key Insights
- *Virginica* flowers tend to have the largest petal dimensions.
- Sepal measurements show more overlap between species than petal measurements.
- Pairplots helped clearly separate species based on petal features.
